# Old Standard TT Bold（加字版 v3.001）

> 本发布包为 **Old Standard TT Bold** 的独立发行版。

## 字体信息

| 项目 | 内容 |
|---|---|
| 字体名称 | Old Standard TT Bold（加字版 v3.001） |
| 风格 | Bold（粗体） |
| 字形总数 | 939 |
| 基础版本 | 官方 v3.000（935 字形） |

## 与官方版的关系

本文件基于 Google Fonts 官方发布的 Old Standard TT Bold v3.000（935 字形）派生：
在官方字形基础上新增上述四字，版本号升至 3.001，并在 name 表（nameID 10）写入
完整中英描述。除新增四字与描述外，不改动官方字形及其余 name 表结构；且官方
OFL.txt 未声明 Reserved Font Name，本加字版沿用「Old Standard TT」系列名称
无需额外书面许可。
